OG image size and tags: why your link preview has no image

Use a 1200 × 630 PNG or JPEG, reference it with a full https:// URL, add twitter:card = summary_large_image, and re-scrape after every change.

Rule 1: size 1200 × 630

1200 × 630 (a 1.91:1 ratio) is the size Facebook recommends and the one X, LinkedIn, Slack and Discord all display well. Export at 2× (2400 × 1260) if you want it sharp on retina screens, but keep the file small. Keep the title big and centred: some apps crop to a square or show a small thumbnail.

Rule 2: a full https:// URL

<meta property="og:image" content="https://example.com/og.png">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">

The Open Graph protocol expects an absolute URL. A relative path like /og.png often shows no image at all.

Rule 3: the large-card tag for X (Twitter)

<meta name="twitter:card" content="summary_large_image">

Without it, X falls back to a small square thumbnail. X reads og:title, og:description and og:image if you don't set separate twitter: tags.

Rule 4: previews are cached

Platforms cache the preview the first time a link is shared. After you change the image, refresh it with LinkedIn Post Inspector or the Facebook Sharing Debugger, or add a version query string (og.png?v=2).

The full tag set to copy

<meta property="og:type" content="website">
<meta property="og:title" content="Your title">
<meta property="og:description" content="One sentence about the page">
<meta property="og:url" content="https://example.com/page">
<meta property="og:image" content="https://example.com/og.png">
<meta name="twitter:card" content="summary_large_image">

FAQ

What is the best OG image size?

1200 x 630 pixels (1.91:1). It displays well on Facebook, X, LinkedIn, Slack and Discord.

Why does my link preview show no image?

The most common causes are a relative og:image URL, an image the crawler can't fetch, or an old cached preview. Use a full https:// URL and re-scrape with LinkedIn Post Inspector or the Facebook Sharing Debugger.

How do I get a large image card on X (Twitter)?

Add <meta name="twitter:card" content="summary_large_image"> alongside your og:image tag.

Do I need separate twitter:image tags?

No. X falls back to the Open Graph tags (og:title, og:description, og:image) when twitter: tags are missing.
